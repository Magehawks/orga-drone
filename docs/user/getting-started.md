# Getting started

**Question:** How do I open Orga Drone and add my drone folders?

1. Start the app (Windows: double-click `orga-drone.exe`).
2. On Home, choose **Add media** (or open **Sources**).
3. Pick a folder that contains your photos and videos. The app only reads them; it does not move or delete originals.
4. Wait for the scan to finish. Unchanged files are skipped on later scans.

**Tips**

- Keep SD cards and drives connected while you work with those files.
- If a drive is offline later, your catalog entries stay; the UI marks them offline.
- Exported videos and the app database live outside your media folder.
