# Export

**Question:** How do I save a shareable file without changing my originals?

## Studio Story → MP4

1. Open the Story and choose Export.
2. Pick resolution and quality: Standard, High, or Best (Best takes longer).
3. Choose a folder **outside** your camera/media folder if you can.
4. Wait for encode. **Cancel** stops a running export.
5. On Windows, use **Open video** or **Show in folder**. Existing files are never overwritten; a free numbered name is used.

Photo-only Stories export as video (up to 1080p). For a full-resolution still for a print shop, use the detail Export tab below.

## One photo or video from detail

1. Open the file → **Export**.
2. **Photos** — optional Image grade, then choose a profile:
   - **Original quality** — full pixel size; exact copy when there are no adjustments and no location data in the file.
   - **High quality / Print** — same full-resolution path; JPEG or PNG; shows output width × height; optional print-size helper shows effective PPI (guidance only).
   - **Social media** — WhatsApp (fit), Instagram or TikTok (center crop). Exact output size is shown.
   - **Custom** — format, size inside the original pixels (never enlarges), JPEG quality when applicable.
3. **Videos** — local MP4 presets only (no Image sliders or photo profiles on video detail).

Nothing is uploaded. The library file is never modified. Graded stills are 8-bit
re-encodes. An exact byte-copy happens only when the file looks free of location
metadata (EXIF GPS and common XMP/GPS markers) and the chosen JPEG/PNG format
matches the source. Unreadable metadata is treated as unsafe for copying.
Re-encoded exports do not carry source location tags.
