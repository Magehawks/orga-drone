# Library and Browse

**Question:** How do I find a flight and keep favorites organized?

1. Open **Browse** (or the media library from the sidebar).
2. Use the filters on the left (date, drone, camera, favorites, …). Empty filter groups stay hidden.
3. Open a photo or video for Info, Location, and Export. Photos also have Image adjustments.
4. Optional: create **Albums** and add files. Albums are labels only; files stay on disk.
5. **Ask the library** understands simple phrases in German or English. It is rule-based, not an AI chat.

**Tips**

- Page size can be 50, 100, or 200. You can add the current page to Studio in bulk.
- Timeline in Browse groups by recording date. It is not the Studio story editor.
- Likely duplicates are listed for review; nothing is deleted automatically.
