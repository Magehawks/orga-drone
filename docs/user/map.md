# Map

**Question:** How do I see where I flew?

1. Open **Flight map** from the sidebar.
2. Browse flights that have GPS. Place names can be hidden if you prefer.
3. Open a clip with GPS for the route on its Location tab.
4. In Studio, optional **flight map** and **telemetry** overlays use stored GPS / sibling SRT data when available.

**Honest limits**

- Speed on the library overlay is estimated from GPS movement.
- Studio HUD shows elapsed time and relative altitude when the SRT has them. Speed and home distance stay “not available” there.
- Map tiles need a network connection the first time; they can be cached locally.
