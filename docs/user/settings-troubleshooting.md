# Settings and troubleshooting

**Question:** Where do I change theme/language, and what if something fails?

## Settings

1. Open **Settings** at the bottom of the sidebar (or the bottom bar on a narrow window).
2. Choose dark, light, or custom theme.
3. Choose German or English.
4. You can clear thumbnail and map-tile caches only — not your library catalog.

## Common problems

| Problem | What to try |
| --- | --- |
| File missing / offline | Reconnect the drive and scan again. Catalog entries stay until the folder is listable. |
| Export fails | Check free disk space and that music/video paths still exist. Read the short error; details are in the app log. |
| Preview looks softer than export | Preview may use a proxy. Trust export timing; colors can differ slightly. |
| Music silent at the start | The soundtrack may start later on the timeline — drag it or check the music start. |
| WebView / window will not open | Install Edge WebView2 Runtime. See packaging notes for Windows. |

Still stuck? Note the version under About and the exact steps. Do not send original media or GPS into public issue trackers.
